# EV Charging Station Performance Analysis

## Project Overview
This project uses Power BI to analyse EV charging station performance across multiple Indian cities.

## Objectives
- Analyse total revenue and charging sessions.
- Compare revenue across cities.
- Study charger type distribution.
- Track energy delivery and session status.
- Evaluate customer ratings.

## Dashboard Features
- Total Revenue
- Total Charging Sessions
- Total Energy Delivered
- Average Customer Rating
- Monthly Revenue Trend
- Revenue by City
- Sessions by Charger Type
- Session Status Distribution
- Energy Delivered by Charger Type

## Tools Used
- Microsoft Power BI
- Microsoft Excel / CSV
- GitHub

## Files
- `EV_Charging_Station_Performance.pbix` — Power BI dashboard
- `EV_Charging_Station_Performance_Dataset.csv` — Dataset
- `EV_Charging_Station_Performance_Presentation.pptx` — Project presentation
- `dashboard_screenshot.png` — Dashboard preview

## How to Use
1. Download the dataset and Power BI file.
2. Open the `.pbix` file in Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard visuals.

## Conclusion
The dashboard provides an overview of EV charging activity, revenue, energy delivery, charger usage, and customer satisfaction.
